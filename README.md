# Python practice

A collection of small Python exercises. Each script runs on its own with Python 3.

## Exercises

- [Finding largest Number.py](exercises/Finding%20largest%20Number.py) uses `if`, `elif`, and `else` to find the largest of three integers. When inputs tie for largest, it reports the first one entered with that value.

## Run an exercise

From the repository root, run the script and enter one integer at each prompt.

```sh
python "exercises/Finding largest Number.py"
```

For example, enter `4`, `9`, and `2` in that order. The script identifies the second number (B) as the largest and prints its value, `9`.
